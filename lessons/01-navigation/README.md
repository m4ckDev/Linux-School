# 01 - Navigation

## Objective

This module teaches how to move around the Linux file system from the terminal.

By the end of this module, you should understand:

- How to check your current location
- How to list files and directories
- How to move between folders
- How absolute and relative paths work
- How to return home quickly
- How to avoid getting lost in the terminal

---

## Commands Covered

~~~bash
pwd
ls
ls -l
ls -la
cd
cd ..
cd ~
cd /
~~~

---

## Core Idea

Linux is built like a file tree.

The top of the tree is:

~~~text
/
~~~

Your personal home folder is usually:

~~~text
/home/username
~~~

Example:

~~~text
/home/m4ck
~~~

When using the terminal, you are always located somewhere inside the file system.

Use this command to see where you are:

~~~bash
pwd
~~~

---

## Navigation Mindset

When moving around Linux, always ask:

1. Where am I?
2. What is inside this folder?
3. Where do I want to go?
4. Am I using the correct path?
