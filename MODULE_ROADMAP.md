# Linux School Module Roadmap

Linux School is built as a structured Linux command line course.

Each module follows this pattern:

```text
Overview
Lesson
Practice
Lab
Challenge
Quiz
```

## Recommended Order

Start here:

```text
Module 00
Module 01
Module 02
Module 03
Module 04
```

Do not skip the early modules if you are new to Linux.

---

## CLI Examples

Open Module 00 lesson:

```bash
bash tools/linux-school.sh open 00 lesson
```

Open Module 03 lab:

```bash

```

