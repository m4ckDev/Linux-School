# Support Linux School

Linux School is a hands-on Linux command line training project built to help beginners, cybersecurity students, homelab builders, and future system administrators learn Linux through real terminal practice.

If this project helped you, consider supporting future development.

---

## Ways to Support

### 1. Star the Repository

The easiest way to support Linux School is to star the GitHub repo.

This helps more people find the project.

---

### 2. Share the Project

Share Linux School with:

- New Linux users
- Cybersecurity students
- Homelab builders
- Help desk learners
- IT training groups
- Anyone trying to get better at the command line

---

### 3. Contribute

You can help improve Linux School by suggesting:

- Better explanations
- New labs
- New challenges
- Quiz improvements
- Typo fixes
- Website improvements
- CLI improvements
