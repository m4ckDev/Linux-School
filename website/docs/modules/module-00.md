# Module 00 — Getting Started

This page is the website landing page for Module 00: **Getting Started**.

## Use the CLI

From the local Linux School repository:

```bash
bash tools/linux-school.sh open 00 overview
bash tools/linux-school.sh open 00 lesson
bash tools/linux-school.sh open 00 practice
bash tools/linux-school.sh open 00 lab
bash tools/linux-school.sh open 00 challenge
bash tools/linux-school.sh open 00 quiz
```

## Learning flow

1. Read the overview.
2. Study the lesson.
3. Complete the practice.
4. Complete the lab.
5. Attempt the challenge.
6. Take the quiz.
