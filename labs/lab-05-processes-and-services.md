# Lab 05 — Processes and Services

## Objective

Complete a hands-on Linux lab focused on **Processes and Services**.

---

## Lab Environment

Use one of the following:

- Ubuntu VM
- Debian VM
- Kali VM
- WSL
- Spare Linux laptop
- Cloud Linux instance

---

## Setup

```bash
mkdir -p ~/linux-school-labs/lab-05
cd ~/linux-school-labs/lab-05
```

---

## Commands Used

```bash
ps top pgrep kill pkill systemctl journalctl
```

---

## Lab Tasks

1. Prepare the lab folder.
2. Run the required commands.
3. Capture important output.
4. Fix at least one intentional mistake.
5. Explain what changed on the system.

---

## Success Criteria

You complete this lab when you can:

- Run the core commands without copying blindly.
- Explain what each command does.
- Read the output correctly.
- Identify and correct a basic issue.
